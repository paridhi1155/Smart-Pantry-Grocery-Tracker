# Smart Pantry & Grocery Tracker

## Project Description

Smart Pantry & Grocery Tracker is a Java-based application used to manage grocery items and pantry records. It allows users to add, view, search, and remove grocery items. It also provides expiry alerts and a grocery report.

## Features

- Add grocery items
- View all grocery items
- Search for a grocery item
- Remove grocery items
- Check expiry status
- Generate grocery reports

## Technologies Used

- Java 8
- Eclipse IDE
- ArrayList
- LocalDate
- Object-Oriented Programming

## Main Modules

1. Grocery Item Management
2. Pantry Management
3. Expiry Checking
4. Grocery Reporting
5. Main Menu
